## 🎯 소개

발맞춤(Balmatchum)은 걷는 속도를 BPM으로 바꾸고, 그 박자에 맞춰 음악을 실시간으로 생성하는 안드로이드 앱입니다.

### 배경

산책이나 러닝 중에 음악을 들을 때, 재생 중인 곡의 박자는 지금의 걸음 속도와 무관합니다. 천천히 걷고 있는데 빠른 곡이 나오거나, 속도를 올렸는데 느린 곡이 이어지는 일이 흔합니다.

### 목적

본 프로젝트는 **걸음 간격을 BPM으로 환산하여 외부 음원 없이 음악을 직접 생성**하고, 걷는 속도와 음악의 박자가 항상 맞도록 하는 것을 목표로 합니다. 걸음을 마치면 그 걸음을 '걸음 곡'으로 저장하여 다시 들을 수 있습니다.

## ✨ 주요 기능

### 🚶 걸음 기반 실시간 음악
| 기능 | 설명 |
|------|------|
| **걸음 감지** | 걸음 감지 센서(`TYPE_STEP_DETECTOR`)로 걸음마다 이벤트 수신 |
| **BPM 계산** | 최근 걸음 간격의 평균으로 실시간 BPM 계산 |
| **음악 생성** | BPM에 맞춰 킥, 하이햇, 멜로디를 규칙 기반으로 재생 |

### 💾 걸음 곡 저장
- 걷기 종료 시 날짜, 걸음 수, 평균 BPM 등을 SQLite에 저장
- 저장된 곡 목록 조회, 정렬, 삭제
- 저장한 곡 정보로 같은 곡 다시 듣기

### 📤 곡 내보내기 (WAV)
- 곡 상세 화면의 **[내보내기 (WAV)]** 버튼으로 걸음 곡을 오디오 파일로 저장
- 재생과 같은 계산 코드(`NoteSequencer`)로 만들어서, 앱에서 듣는 것과 같은 곡이 파일로 나옴 (옛 곡·새 곡 모두)
- 진행률 표시와 **[취소]** 지원, 저장 후 **[공유]**로 다른 앱에 보내기

| 항목 | 내용 |
|------|------|
| **파일 형식** | WAV, 22050Hz, 모노, 16bit PCM (5분 곡 약 13MB) |
| **파일 이름** | `balmatchum_yyyyMMdd_HHmm_BPM평균.wav` (예: `balmatchum_20261119_1305_BPM108.wav`) |
| **저장 위치** | Android 10 이상: `다운로드/Balmatchum` 폴더 (권한 요청 없음) / Android 9 이하: 앱 캐시에 만든 뒤 공유 시트로 원하는 곳에 저장 |
| **소리** | 곡에 저장된 스케일·테마·비트를 그대로 반영, 설정의 볼륨과 관계없이 100%로 만듦. 끝에 1.5초 여운, 최댓값 0.95로 정규화 |

### 🎛️ 설정
- 스케일(분위기) 선택
- 사운드 테마 선택 (8bit, Lo-fi, 피아노)
- 볼륨 조절, 비트 켜기, 걷는 동안 화면 켜두기

## 🚀 시작하기

### 사전 요구사항

- **Android Studio** (최신 안정 버전 권장)
- **Java** 기반 프로젝트 (Android Studio에 포함된 JDK 사용)
- **실행 기기**: 안드로이드 폰(USB 또는 무선 디버깅) 또는 에뮬레이터
- **최소 SDK**: 26

### 설치

1. **저장소 클론**
   ```bash
   git clone [저장소 주소]
   ```

2. **Android Studio에서 열기**
    - `File` → `Open` → 클론한 `Balmatchum` 폴더 선택
    - Gradle 동기화가 끝날 때까지 기다립니다.

### 실행

#### 📱 실제 폰에서 실행
1. 폰의 `설정` → `개발자 옵션`에서 **USB 디버깅** 또는 **무선 디버깅**을 켭니다.
2. Android Studio 상단 기기 목록에서 폰을 선택합니다.
3. `Run` 버튼 클릭 또는 `Shift + F10`
4. 처음 실행하면 **신체 활동** 권한을 허용합니다.

#### 💻 에뮬레이터에서 실행
1. 기기 목록에서 에뮬레이터(예: Pixel 8 Pro)를 선택하고 실행합니다.
2. 에뮬레이터에는 걸음 센서가 동작하지 않으므로 **"걸음 시뮬레이션"** 버튼으로 걸음을 만듭니다.

## 📖 사용법

### 1️⃣ 걷기 시작
1. 앱을 실행하고 **[시작]** 버튼 클릭
2. 폰을 들고 걸으면 걸음마다 가운데 원이 퍼져 나가고, BPM과 걸은 시간·걸음 수·평균 BPM이 실시간으로 표시되며, 박자에 맞춰 소리가 재생됩니다.
3. 에뮬레이터(걸음 센서 없음)에서는 시작 버튼 위에 나타나는 **[걸음 시뮬레이션]** 버튼을 일정한 박자로 누릅니다.
4. 걷는 중에 다른 탭으로 이동하면 걷기가 자동으로 정지·저장됩니다.

### 2️⃣ 걷기 종료
1. **[정지]** 버튼 클릭
2. 걸은 시간, 걸음 수, 평균 BPM이 표시됩니다.

### 3️⃣ 걸음 곡 보기
1. 하단 탭에서 **기록** 선택
2. 오른쪽 위 선택 상자로 정렬 방식(최신순, 오래된순, BPM 높은순, 걸음 많은순)을 바꿀 수 있습니다.
3. 곡을 길게 누르면 삭제할 수 있습니다.
4. 곡을 누르면 곡 상세 화면이 열립니다. BPM 변화 그래프를 보고, **[다시 듣기]**로 걸을 때와 같은 멜로디를 다시 들을 수 있습니다.
5. 진행 막대를 끌어 원하는 위치부터 들을 수 있고, **[삭제]**로 곡을 지울 수 있습니다.
6. **[내보내기 (WAV)]**를 누르면 곡을 WAV 파일로 만들어 `다운로드/Balmatchum` 폴더에 저장합니다. 완료 창의 **[공유]**로 메신저·드라이브 등에 보낼 수 있습니다.

### 4️⃣ 설정 바꾸기
1. 하단 탭에서 **설정** 선택
2. 스케일(펜타토닉, 마이너 펜타토닉, 장음계), 사운드 테마(8bit, Lo-fi, 피아노), 볼륨, 비트 켜기, 걷는 동안 화면 켜두기를 바꿉니다.
3. 값을 바꾸는 즉시 저장되고, 걷기 화면으로 돌아가면 바로 반영됩니다.
4. 걷기를 저장할 때 그때의 스케일, 테마, 비트 설정이 곡에 함께 저장되어, 다시 듣기는 항상 저장 당시와 같은 소리로 재생됩니다.
5. **[설정 초기화]**로 모든 설정을 기본값으로 되돌릴 수 있습니다. (저장된 곡에는 영향 없음)

## 🎼 음악 생성 방식

곡마다 멜로디 알고리즘 버전(`melody_version`)을 저장해서, 다시 들을 때 그 곡을 만든 방식 그대로 재생합니다.
새로 걷는 곡은 **버전 1**, 업데이트 전에 저장된 곡은 **버전 0**입니다.

### 공통

| 요소 | 규칙 |
|------|------|
| **박자 단위** | 16분음표 (한 칸 길이 = 60000 / BPM / 4 ms), 16칸 = 1마디 |
| **스케일** | 펜타토닉 `0,2,4,7,9,12` / 마이너 펜타토닉 `0,3,5,7,10,12` / 장음계 `0,2,4,5,7,9,11,12` (반음) |
| **음높이** | 도(C) 음 샘플의 재생 속도(rate)를 바꿔 조절. 속도 = 2^(반음/12), SoundPool 허용 범위 0.5 ~ 2.0배 |
| **다시 듣기** | 저장된 시드로 같은 곡을 만들고, 걸음마다의 BPM 기록(값 하나 = 60000/BPM ms)을 순서대로 적용 |
| **비트 끄기** | 드럼만 재생하지 않음. 난수는 똑같이 뽑으므로 멜로디는 비트를 켰을 때와 완전히 같음 |

### 버전 1 — 새 곡 (`SongComposer`)

| 요소 | 규칙 |
|------|------|
| **시드** | 곡 시드 하나로 용도별 `Random` 3개를 만듦: 곡 개성 / 멜로디 / 리듬. 호출 순서와 횟수가 고정이라 같은 시드면 항상 같은 곡 |
| **곡 개성** | 곡 시작 때 한 번 정함: 멜로디 음색(테마 풀에서 1~2개), 프레이즈 길이(4~8음), 리듬 패턴(4종), 코드 진행(4종) |
| **멜로디** | 프레이즈 A를 만들고 **A → A' → B → A'** 순서로 반복 (A' = 끝음을 조금 바꾼 A, B = 새 프레이즈) |
| **코드 진행** | 코드 하나가 **4마디**씩 이어지고 4개를 돌면 16마디 (예: I-vi-IV-V). 박 첫 칸의 멜로디 음은 코드 구성음으로 맞춤 |
| **베이스** | 매 마디 첫 박에 지금 코드의 뿌리음 (마림바 베이스, 재생 속도 0.75 ~ 1.41배) |
| **음역** | 기준 도에서 아래 12반음 ~ 위 12반음 (두 옥타브) |
| **걸음 속도별 리듬** | 95 BPM 미만: 4칸 간격 위주로 듬성듬성 / 95 ~ 124: 2칸(8분음표) 위주 / 125 이상: 1칸(16분음표)도 섞어 촘촘하게 |
| **강약·쉼표** | 마디 첫 박이 가장 크고 엇박·16분음표 자리는 작게. 프레이즈 음의 약 10%는 쉼표 |
| **리듬** | 패턴표(기본 / 포 온 더 플로어 / 하프타임 / 그루브)에 따라 킥·스네어·하이햇·장식 타악기. 마디마다 어떤 소리를 쓸지 시드로 고름 (킥 2종, 스네어/클랩, 하이햇 2종, 가끔 열린 하이햇, 셰이커/우드블록) |

**테마별 소리 풀** (`SoundPalette`)

| 테마 | 멜로디 음색 | 베이스 | 리듬 |
|------|------|------|------|
| **8bit** | `note`, `mel_glockenspiel` | `bass_marimba` | 테마의 기존 킥·하이햇 + `v2_kick`, `snare`, `clap`, `v2_hat_closed`, `hat_open`, `shaker`, `woodblock` |
| **Lo-fi** | `lofi_note`, `mel_fmpiano`, `mel_marimba` | `bass_marimba` | (위와 같음) |
| **피아노** | `piano_note`, `mel_piano`, `mel_glockenspiel` | `bass_marimba` | (위와 같음) |

### 버전 0 — 업데이트 전 곡 (옛 알고리즘, 그대로 보존)

| 요소 | 규칙 |
|------|------|
| **킥** | 매 박(4칸마다) |
| **하이햇** | 엇박(4칸 중 3번째 칸) |
| **멜로디** | 8분음표마다 선택한 음계에서 한 칸 위, 아래, 제자리 중 무작위 이동 (기준음 위로 0 ~ 12반음) |
| **사운드 테마** | 테마마다 기존 멜로디·킥·하이햇 샘플 3개만 사용 (8bit, Lo-fi, 피아노) |

    │   ├── WavIO.java            # WAV 읽기(data 청크 디코딩)·쓰기(44바이트 헤더)
    │   ├── SongDbHelper.java     # 걸음 곡·설정값 SQLite 저장·조회·삭제
    │   ├── SongListActivity.java # 걸음 곡 목록 화면 (정렬, 삭제)
    │   ├── SongDetailActivity.java # 곡 상세 화면 (다시 듣기, 진행 막대, 삭제, 내보내기·공유)
    │   ├── BpmGraphView.java     # BPM 변화 선 그래프 (Custom View, Canvas)
    │   ├── WalkVisualizerView.java # 걸음마다 원이 퍼지는 비주얼라이저 (Custom View, Canvas)
    │   ├── SettingsActivity.java # 설정 화면 (스케일, 테마, 볼륨, 스위치)
    │   └── NavHelper.java        # 공통 상단 바·하단 탭 설정과 탭 이동
    └── res/
        ├── layout/               # 화면 레이아웃 (include_toolbar, include_bottom_nav, include_stat_tiles 공통 조각 포함)
        ├── menu/bottom_nav.xml   # 하단 탭 메뉴 (걷기 / 기록 / 설정)

        ├── xml/file_paths.xml    # 공유(FileProvider)할 수 있는 폴더 (캐시/exports)
        └── raw/                  # 소리 샘플 21개 (기존 9개 + VCSL 12개, 리소스 출처 참고)

## 🎧 리소스 출처

### 소리 샘플 (`app/src/main/res/raw`)

**기존 9개 — 자체 제작 (Python 합성)**

- `note`, `kick`, `hat` (8bit), `lofi_note`, `lofi_kick`, `lofi_hat` (Lo-fi), `piano_note`, `piano_kick`, `piano_hat` (피아노)
- 외부 음원을 쓰지 않고 프로그램으로 합성한 소리입니다. 업데이트 전에 저장된 곡(`melody_version` 0)은 이 9개만으로 재생됩니다.

**새 소리 12개 — [Versilian Community Sample Library (VCSL)](https://github.com/sgossner/VCSL), CC0**

| 용도 | 파일 |
|------|------|
| 멜로디 | `mel_fmpiano`, `mel_glockenspiel`, `mel_marimba`, `mel_piano` |
| 베이스 | `bass_marimba` |
| 리듬 | `v2_kick`, `snare`, `clap`, `v2_hat_closed`, `hat_open`, `shaker`, `woodblock` |

- VCSL 샘플을 22050Hz 모노 16bit WAV로 변환하고, 앞부분 무음을 제거하고, 음량을 정규화했습니다.
- CC0(퍼블릭 도메인) 라이선스라 출처 표기 의무는 없지만, 원 출처를 밝혀 둡니다.
